INSTALLATION STEPS:
===============================================================================

STEP 1: Extract Package
   - Extract erpsins.zip to your web directory
   - Recommended: /var/www/html/erpsins (Linux)
   - Recommended: C:\xampp\htdocs\erpsins (Windows)

STEP 2: Configure Environment
   - Copy .env.example to .env
   - Edit .env file with your settings:
     * Database credentials
     * Application name
     * Debug mode (false for production)
     * Session settings

STEP 3: Create Database
   - Open MySQL command line or phpMyAdmin
   - Run: CREATE DATABASE erpsins CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   - Or use phpMyAdmin GUI

STEP 4: Import Database
   - Command line: mysql -u root -p erpsins < database/schema.sql
   - Or use phpMyAdmin import feature
   - Verify tables are created (should be 11 tables)

STEP 5: Set Permissions
   - Linux/Mac:
     chmod -R 755 /path/to/erpsins
     chmod -R 777 /path/to/erpsins/logs
     chmod -R 777 /path/to/erpsins/tmp
     chmod -R 777 /path/to/erpsins/cache
     chmod -R 777 /path/to/erpsins/public/uploads

   - Windows:
     Right-click folders → Properties → Security
     Give "Full Control" to IIS_IUSRS or IUSR

STEP 6: Configure Web Server
   - Apache: Point DocumentRoot to public/ directory
   - Nginx: Configure root to public/ directory
   - Enable URL rewriting
   - Restart web server

STEP 7: Test Installation
   - Open browser: http://localhost or your domain
   - You should see login page
   - If errors, check logs/ directory

STEP 8: First Login
   - Use default credentials (see below)
   - Change password immediately
   - Update company settings

STEP 9: Security Check
   - Generate new APP_KEY in .env
   - Set APP_DEBUG=false for production
   - Enable HTTPS/SSL
   - Review file permissions
   - Delete or modify demo users

STEP 10: Customize
   - Update company information in settings
   - Add your logo (public/assets/images/)
   - Configure tax rates
   - Set up user accounts
   - Import your data (if migrating)

WEB SERVER CONFIGURATION:
===============================================================================

Apache Configuration (.htaccess included):
-------------------------------------------
<VirtualHost *:80>
    ServerName erp.yourdomain.com
    DocumentRoot /path/to/erpsins/public

    <Directory /path/to/erpsins/public>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/erp_error.log
    CustomLog ${APACHE_LOG_DIR}/erp_access.log combined
</VirtualHost>

Nginx Configuration:
--------------------
server {
    listen 80;
    server_name erp.yourdomain.com;
    root /path/to/erpsins/public;

    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.0-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
